# Taiwan Weather Forecast Web App (台灣天氣預報系統)

打造你的 AI Coding Agent - Antigravity x Gemini x GitHub 專案實作作業。

## 專案簡介
本專案為使用 Python 與 Streamlit 打造的台灣即時與一週天氣預報 Web 應用程式。整合中央氣象署（CWA）開放資料 API 與 SQLite 資料庫，提供互動式天氣查詢、視覺化圖表與台灣地圖氣象呈現。

## 技術架構 (Tech Stack)
- **語言**: Python 3.14+
- **前端展示**: Streamlit
- **資料儲存**: SQLite
- **資料來源**: 中央氣象署開放資料平台 (CWA Open Data API)
- **視覺化**: Plotly / Folium (台灣互動地圖與氣溫走勢圖)

## 快速開始 (Quick Start)
```bash
# 1. 安裝相依套件
pip install -r requirements.txt

# 2. 啟動 Streamlit 網頁應用程式
streamlit run app.py
```
